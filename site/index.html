How it works

Survey. Spot the deadwood. Timber!

Point Timber at your home folder and it measures every file in seconds. Folders grow into trees, so the giants are obvious. Caches and build junk show up as dead trees. Walk into any folder, inspect any tree, and chop it with a satisfying thunk.

Features

A field guide to your storage.

The forest view

Tree height tracks the square root of size, so canopy area tracks bytes. Folders grow as pines, media as blossoms, installers as birches, apps as maples.

Git-aware

Checks every repo and worktree for uncommitted changes and unpushed commits before you swing. Chopped worktrees are detached cleanly so their branch frees up.

Nothing is deleted

Chops go to the Trash and into a log. ⌘Z plants them back. System folders, keys, settings and your Photos library are off limits.

A 3D survey

Scanning isn't a progress bar. It's a low-poly island under a lidar sweep, sprouting a tree for every folder it measures.

Private & local

Your files never leave your Mac.

Timber is a native app that reads your disk and keeps what it learns to itself. No account, no cloud, no upload. The code is open, so you don't have to take our word for it.

1

100% on-device scanning

Measuring, deadwood rules and git checks all run locally.

2

The Ranger is opt-in

Only if you add a key, and only names, sizes and dates. Never file contents.

3

Anonymous counts, with an off switch

Things like “a 1–10 GB cache was chopped”. Never file names or paths. Turn it off in Settings.

FAQ

Questions from the trail.

Does Timber delete my files?

Never. Chopping moves things to the Trash and logs it, and ⌘Z puts them back. Space comes back when you empty the Trash. Timber can do that for you, but only after you confirm.

Why does it ask for Full Disk Access?

It doesn't need it, but macOS hides some folders (Mail, Safari, other apps' containers) from apps without it. Without it, Timber simply shows those as locked. Grant it in System Settings → Privacy & Security if you want the full picture.

Is it safe to chop node_modules, DerivedData and caches?

Yes, they're rebuilt or re-downloaded when needed. Timber marks those as “safe”. Anything that might be personal is marked “look first”, and some things (your home folder, Library, Documents roots, keys, Photos libraries) can't be chopped at all.

What about git repos and worktrees?

Timber checks for uncommitted changes and commits that exist nowhere else, and warns you before chopping. Bulk “clear deadwood” skips them entirely. Chopped worktrees are detached from git cleanly, and undo restores both.

What's the Ranger / Jev?

An optional second opinion powered by TypeSafe's Jev, a fast model that returns typed judgments instead of chat. Add your own TypeSafe key in Settings. Timber applies its own safety policy on top of Jev's answers.

Which Macs does it run on?

Any Mac on macOS 14 Sonoma or later, Apple silicon or Intel.
